# Security

## Reporting a vulnerability

Report it privately, through GitHub's private vulnerability reporting on this repository: the **Security** tab → **Report a vulnerability**, or [directly here](https://github.com/rockarxiv/Engineering-Orchestrator/security/advisories/new).

**Do not file it as a public issue**, and do not describe it in a pull request, a discussion or a comment. A public report hands the problem to everyone before there is a fix.

Say what you found, which version it affects, and how to reproduce it. The report stays private between you and the maintainer while it is looked at and fixed.

## Supported versions

Only the [latest release](https://github.com/rockarxiv/Engineering-Orchestrator/releases/latest) is supported. Fixes land in a new release rather than being backported, and an installed EO updates itself to it — *Settings → Updates* says when one is out.
