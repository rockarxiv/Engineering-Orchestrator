# EO — working agreement

**The working agreement for this repository is [`CLAUDE.md`](./CLAUDE.md). Read it before writing any code.**

It is not named for one backend. The name is Claude Code's convention and this file is Codex's; both point at the same document, because a repository with two working agreements has none. If you are reading this, open `CLAUDE.md` now — it is short, and the thirteen invariants in it are load-bearing: code that breaks one of them is wrong even if its own tests pass.

Nothing is duplicated here on purpose. A second copy of the rules is a second copy to drift, and the rules are the last thing that should say two different things depending on which agent read them.
